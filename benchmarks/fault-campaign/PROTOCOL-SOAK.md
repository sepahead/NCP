## Why this follow-up exists

In the soak trials of the [fault campaign](PROTOCOL.md), the client kept every call time, 8 bytes per call in Rust.
Its resident memory therefore grew with the number of calls, so hypothesis F7 cannot separate the SDK from the harness.
These soaks use clients that keep a fixed reservoir of 4096 call times.

## Trials

- **rust:** the Rust client and the Rust owner of `benchmarks/pipelined-ack`, 1,000,000 lockstep calls.
- **python:** `LocalClient` and the Python echo owner, 200,000 lockstep calls.

Both use SDK 1.0.1. The sampler records the resident memory and open descriptors of the client and the owner every 0.5 s.
Three blocks run both soaks once, in an order shuffled with the seed 20261027.

## Hypotheses

- **S1.** After the first 10 percent of each soak, the resident memory of the client and of the owner grows by less than 2 percent.
- **S2.** The number of open descriptors of the client and of the owner stays constant after the first sample.

A hypothesis holds when its criterion holds.
