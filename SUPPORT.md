# Support

NCP is research software maintained by **Sepehr Mahmoudian** (**@sepahead**).
Repository HEAD is the unreleased, release-blocked `1.0.0-rc.1` candidate; the
latest immutable annotated source tag is `v0.8.0`. Do not use support responses as security,
safety, interoperability, or release certification.

Support is best effort. The project currently promises no response SLA or candidate
support period.

- **Bugs / feature requests** — open a [GitHub issue](https://github.com/sepahead/NCP/issues) using the templates.
- **Questions / ideas** — use [GitHub Discussions](https://github.com/sepahead/NCP/discussions).
- **Security** — use the [private vulnerability report form](https://github.com/sepahead/NCP/security/advisories/new)
  and see [`SECURITY.md`](SECURITY.md); do not file public vulnerability issues.

Good places to start: the spec (`NEURO_CYBERNETIC_PROTOCOL.md`), the design
[`RATIONALE.md`](RATIONALE.md), the [`ROADMAP.md`](ROADMAP.md), and the explicit
gate ledger [`RELEASE_READINESS.md`](RELEASE_READINESS.md).
